**为什么值得关注？**

- 🧭 **一个论点** — 可靠 agent 缺的不是推理，是运行时：上下文、放权、沉淀、证明。
- 📮 **在真实日常里干活** — 飞书日报助手：日报可追溯，回复走审批，验证过的经验自动复用。
- 🪜 **这个量级不要向量库** — 文件 + BM25，1/5 检索量持平答对率，token **−62%**。
- 🧬 **自进化不卡冷启动** — skill 只为出生后的回复负责，换版本必须过人。
- 📊 **反注水评测** — 超时计失败，A–D 证据分级，跑不出的数字不写。
